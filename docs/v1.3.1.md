# v1.3.1

> **稳定性修复版本：后台输入失焦自愈、YOLO 首启竞态修复、删车流程提速。**

## 升级须知

- 无需改动配置。YOLO 默认置信度由 0.7 调整为 0.65，仅影响首次使用（无配置文件）的默认值；老用户界面滑条保存的值不受影响

## 修复

### 后台输入：游戏失焦后 W 键长按失效
- 现象：跑图中点了一下其他软件再切回来，车停住不动，脚本"不再油门"，只能等完赛/卡死保护触发才恢复
- 原因：后台长按依赖 auto-repeat 按键包（lParam bit30=1），游戏失焦清空键状态后会过滤自动重复包，长按永久失效
- 修复：后台输入循环每 2 秒对按住键改发一次"新鲜按下"包，游戏键状态 2 秒内自愈

### YOLO 识别：首次启动静默降级模板匹配
- 现象：第一次下载释放使用，即使勾选了 YOLO 识别，实际仍走图像匹配，且无任何提示
- 原因：首次启动模型释放（后台拷贝数十 MB）与 YOLO 加载竞态，读到写了一半的模型文件导致加载失败；原逻辑单次失败即永久放弃，失败原因只打控制台
- 修复：
  - 资源释放改为原子方式（.tmp 拷贝 + 改名），读取方永远不会看到半截文件
  - YOLO 加载改为最多重试 3 次（间隔 5 秒），失败原因与推理后端（DirectML/CPU）写入界面日志
  - 勾掉再勾选 YOLO 开关可立即触发重试

### YOLO 模式：等级标签不再每次回退模板匹配
- 现象：YOLO 已命中目标车卡，日志里却仍出现 classS1702.png 模板匹配
- 原因：YOLO 等级标签置信度门槛沿用模板的 0.72，但该类别实测 conf 仅 0.5~0.7，几乎必然回退冗余模板校验
- 修复：YOLO 分支等级标签 conf ≥0.50 直接过硬校验（已有车型分类 + NEW 角标双重交叉验证保底），并放宽标签的车卡归属判定；模板路径阈值不变

### 删车流程：补上点击车卡后的 Enter 动作
- 点击车卡后"从车库移除"按钮只是半露出，原逻辑先盲找 1.5 秒（永远过不了线）再 Enter 重找，每辆车白浪费 2 秒+
- 现改为：点击 → Enter → 等 0.7s → 找按钮，单段完成

### 手动停止后清空超抽记忆页码
- 手动停止（F8 / 停止按钮）后通常会增删车辆，记忆页码不再可靠，下次超抽从第 1 页重新搜索
- 任务正常完成的自动停止仍保留页码记忆（"下次从第 N 页开始搜"功能不受影响）

## 改进

- 后台输入循环异常防护：单次发送失败只计数，不再静默杀死整个重复线程
- YOLO 识别勾选框下方新增置信度滑条说明文字
- YOLO 默认置信度 0.7 → 0.65
