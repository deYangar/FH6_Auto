# v1.3.4

## 🔧 修复

### 删车筛选失效：5 步跳搜导致短文本目标被跳过

- **现象**：v1.3.3 删车筛选阶段搜索 S1 等短文本目标时，列表持续向下滑动直到判到底，目标选项缺失，筛选失败中止删车。跑图选车筛选不受影响（目标均为长文本且靠前，首屏 OCR 即命中）
- **根因**：v1.3.3 将筛选搜索从 `_search_and_focus`（逐键搜索：每按 1 次 ↓ 就 OCR 一次）改为 `_search_with_skip`（5 步跳搜：每按 5 次 ↓ 才 OCR 一次）。短文本目标（如 S1，仅 2 字符）OCR 偶发漏识别时，5 次 ↓ 后目标已滚出可见区，后续再也找不到。同时新代码缺少 `first_check` 保护，step 0 未按键即开始累积卡底计数
- **修复**：回退 filter_nav.py 筛选搜索逻辑至 v1.3.2 的 `_search_and_focus` 逐键搜索，恢复 `first_check` 保护。v1.3.3 的其他改进（YOLO 校验、专精稳定化、等待硬上限等）全部保留
- **影响范围**：仅 filter_nav.py（-133/+100 行），不涉及其他模块
