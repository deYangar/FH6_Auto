# v1.3.2

> **热修复版本：修复 v1.3.1 删车流程误上车的问题，删车逻辑回退至稳定的两段式判定。**

## 升级须知

- 无需改动配置，直接替换主程序即可
- 本版本仅包含删车流程修复，其余行为与 v1.3.1 完全一致

## 修复

### 删车流程：筛选后点击第一辆车会误上车（[#26](https://github.com/deYangar/FH6_Auto/issues/26)）

- 现象：删车筛选完成后，游戏默认已选中左上角第一辆车。此时进入删车流程，脚本点击车卡后人物直接上车，后续找不到移除按钮，整个流程中断
- 原因：v1.3.1 为省去每车 2 秒的盲找等待，将删车逻辑改为「点击车卡 → 无条件按 Enter → 找移除按钮」单段式。但筛选后第一辆车处于**已选中**状态，点击车卡会直接打开车辆菜单，紧跟的 Enter 选中了菜单第一项（上车），导致误上车
- 修复：回退至 v1.3.0 的两段式逻辑——
  1. 点击车卡后，先直接查找「从车库移除」按钮（阈值 0.70）
  2. 找到则直接点击（点击打开的菜单中即可命中按钮，无需 Enter）
  3. 未找到时才按 Enter 呼出完整菜单，再查找一次（阈值 0.75）
  4. 仍未找到则 ESC + 右移跳过该车
- 代价：无法移除的车辆每辆多约 1.5 秒查找时间，换取流程正确性
