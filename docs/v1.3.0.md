# v1.3.0

> **本次更新采用 YOLO 深度学习识别超抽选车与删车，相较传统图片匹配，速度与准确性均大幅优化。**

## 升级须知

- 本次集成 YOLO 深度学习识别，安装包体积增加约 37MB
- 无需手动操作：首次启动自动释放模型到 exe 旁边 `onnx_models/yolo_best.onnx`
- 自训模型直接覆盖该文件即可生效（内置模型永远不会覆盖外部文件）

## 新功能

### YOLO 识别（超抽选车，默认开启）
- 深度学习模型识别"全新车卡 + NEW 角标"双目标，方案1（兰博基尼）等车卡识别稳定性大幅提升
- 防误选双保险：NEW 角标交叉验证 + 等级模板二次校验，避免误选非全新车
- 列优先选车顺序（列内上→下，列间左→右），与视觉扫描习惯一致
- 空页快速翻页：连续 ≥6 帧且 ≥2.5 秒无目标提前翻页，不再空等 15 秒超时
- 界面提供识别开关 + 置信度滑条（默认 0.7，即时生效，设置落盘）
- 关闭识别或模型缺失时自动降级原模板匹配，旧流程不受影响

### 标注训练工具包（仓库内 yolo_tool/）
- 网页截图标注（模型辅助打标）→ 一键续训 → ONNX 导出 → 一键部署主程序，全流程闭环
- 用法见仓库 yolo_tool/README.md

## 改进

- YOLO 模型外置：更新模型只需替换 exe 旁 `onnx_models/yolo_best.onnx`，免重编译
- 超级抽奖默认改为模式 2（从设计与喷涂开始）
- UI：YOLO 设置与"等待指令"按钮同列竖排
- Steam/Xbox 平台分离重构：平台模块切换改为运行时 hook，告别编译期文件 swap 污染（PR #23，感谢 @hui-shao）
- 修复版本更新弹窗的按钮异常（askyesno 对话框）（PR #23，感谢 @hui-shao）
- 标注工作台：新增"删除文件"按钮（图+标注送回收站可还原）、截图失败自动重试、模型打标自动去重（互斥类重叠框）、默认置信度 0.5

## 修复

- 修复 YOLO 分支点击不中车（坐标未加游戏窗口屏幕区域偏移）
- 修复空页每页空耗 15 秒超时
- 修复真全新车被误拒（NEW 角标校验阈值与车卡阈值解耦）
